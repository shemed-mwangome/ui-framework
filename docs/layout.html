Mobile-first layout

Responsive flex and CSS grids.

Build conventional 12-column layouts or automatic card grids using a small set of predictable classes. Three grid systems are available — pick whichever fits the layout: the 12-column flex grid for classic responsive forms/dashboards, the explicit CSS grid for fixed multi-column layouts with row support, or the automatic CSS grid for "as many cards as fit" layouts.

Containers

Width-constrained wrappers that center content and add side padding. ui-container-fluid is always 100% wide; the others cap out at a breakpoint and stay fluid below it.

ui-container-sm (36rem)
ui-container-md (48rem)
ui-container-lg (64rem)
ui-container-xl (75rem)
ui-container-xxl (87.5rem)
ui-container-fluid (always 100%)
<div class="ui-container-lg">...</div>
<div class="ui-container-fluid">...</div>

12-column flex grid

A .ui-row wrapping any number of .ui-col-* children. Unsuffixed classes (ui-col-6) apply at all widths; -sm-/-md-/-lg- apply from that breakpoint up. Every breakpoint has the full 1–12 range plus auto (content-sized) and the bare form (equal-width, grows to fill).

Explicit CSS grid

A true 12-column CSS grid (.ui-grid) with .ui-span-1–.ui-span-12 children. Unlike the flex grid, items can wrap to a new row without extra markup, and --ui-grid-columns can change the column count. Below 48rem every spanned item automatically becomes full-width.

Automatic CSS grid

Fills a row with as many equal-width columns as fit, each at least --ui-grid-min wide, wrapping the rest to new rows — no breakpoints to manage. Use the ui-css-grid-xs/-sm/-lg/-xl modifiers to change the minimum column width (avoids an inline style attribute, which a strict CSP may block).
