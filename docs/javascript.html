Dependency-free interactions

Declarative data attributes and a small JavaScript API.

Most interactions work through data-ui-* attributes. Programmatic APIs are exposed through the global UI object.

Initialization

The bundle automatically initializes components at DOM ready. Initialize newly inserted HTML manually:

UI.init(document.querySelector("#newContent"));

Public APIs

Everything hangs off the global UI object. Most components also work purely through data-ui-* attributes with no JavaScript calls at all — these methods are for programmatic control.

How to…

Show a toast

UI.toast.show({
  type: "success",       // success | danger | warning | info
  title: "Saved",
  message: "The record was saved successfully.",
  duration: 4000,         // ms before auto-dismiss; 0 disables it
  position: "top-end"     // top-start | top-end | top-center | bottom-start | bottom-end | bottom-center
});

Show an inline alert

UI.alert.create({
  target: "#messageArea", // selector or element; defaults to document.body
  type: "danger",
  title: "Validation failed",
  message: "Please correct the highlighted fields.",
  dismissible: true,      // set false to hide the close button
  prepend: true,          // insert before existing children instead of appending
  duration: 0             // > 0 to auto-dismiss like a toast
});

Ask for confirmation before a destructive action

UI.confirm({
  title: "Revoke access",
  message: "This will immediately revoke the account access.",
  variant: "danger",       // primary | danger; danger focuses Cancel by default
  confirmText: "Revoke access",
  cancelText: "Cancel"
}).then(function (confirmed) {
  if (confirmed) {
    // proceed with the revoke request
  }
});

Open and close a modal from code

var modal = document.getElementById("assignModal");
UI.modal.open(modal);
// ...
UI.modal.close(modal);

React to a date range or table change

document.querySelector("[data-ui-date-range]")
  .addEventListener("ui:daterange:change", function (event) {
    console.log(event.detail.start, event.detail.end);
  });

document.querySelector("[data-ui-table]")
  .addEventListener("ui:table:change", function (event) {
    console.log(event.detail.page, event.detail.totalPages);
  });
