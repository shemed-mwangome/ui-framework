Dependency-free interactions

Declarative data attributes and a small JavaScript API.

Most interactions work through data-ui-* attributes. Programmatic APIs are exposed through the global UI object.

Initialization

The bundle automatically initializes components at DOM ready. Initialize newly inserted HTML manually:

UI.init(document.querySelector("#newContent"));

Public APIs

APIPurpose
UI.modal.open(element)Open a modal
UI.modal.close(element)Close a modal
UI.offcanvas.open(element)Open an offcanvas panel
UI.toast.show(options)Create a toast
UI.alert.create(options)Create an inline alert
UI.multiselect.build(select)Enhance a multiple select

Custom events

Components emit bubbling events such as ui:modal:shown, ui:modal:hidden, ui:offcanvas:shown, ui:tab:shown, and ui:alert:close.

document.addEventListener("ui:modal:shown", function (event) {
  console.log("Opened modal:", event.target.id);
});
