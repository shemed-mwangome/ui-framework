Production-ready starter framework

One framework, two delivery styles.

Use the bundled single CSS and JavaScript files for simple deployment, or load modular component files when you need finer control.

Get started Browse components Try it now, no setup

Two distributions

Choose the deployment style that fits your project. Both distributions provide the same classes and behavior.

Simple

Single bundle

Use dist/ui-framework.css and dist/ui-framework.js.

  • Easy server-side integration
  • No build step
  • All components included
Flexible

Modular components

Load only the CSS and JavaScript files required by your page.

  • Smaller page payloads
  • Easy source customization
  • Independent components
