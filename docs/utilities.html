Utility-first helpers

Compose layouts directly in markup.

Utilities cover display, flexbox, spacing, sizing, typography, colors, borders, shadows, visibility, and interactions. Every utility below carries !important, so it always wins over component classes — that's deliberate, the same convention Bootstrap uses, so a utility applied inline in markup never has to fight specificity with a component's own CSS.

Spacing

Every pattern below accepts 0 through 8 (0, .25rem, .5rem, .75rem, 1rem, 1.5rem, 2rem, 3rem, 4rem), plus ui-mx-auto for horizontal centering.
