Installation

Start without changing your existing theme.

The framework uses the ui- prefix and scoped base styles, making it suitable for any server-rendered application — JSP, PHP, Rails, Django, or plain static HTML — that already uses Bootstrap, CoreUI, or custom master styles.

New here? Try it in 10 seconds

No server, no build step, no account. Download or clone the repository, then double-click quick-start.html in the project root to open it directly in your browser (no http:// needed — a plain file:// path works). It loads the two bundled files and shows a working button, so you can confirm everything is wired up before touching any of your own pages.

How it works, in plain terms

If you've never used a component library before, here's the whole mental model — there isn't more to it than this:

  • CSS classes style things. Every class starts with ui- (e.g. ui-btn, ui-card) specifically so it can't collide with your existing CSS. Write plain HTML and add these classes the same way you'd add any CSS class.
  • data-ui-* attributes trigger behavior — you write zero JavaScript. For example, a button with data-ui-modal-open="#myModal" opens a modal when clicked. The framework's JavaScript file scans the page for these attributes once it loads and wires up the click handlers for you automatically.
  • Nothing needs to be "initialized" for content that's already in the page when it loads. You only call UI.init(element) manually if you insert new HTML with JavaScript after the page has loaded (see JavaScript API).

That's it. Everything else in these docs is just the full list of available ui-* classes and data-ui-* attributes and what each one does.

Option 1: single CSS and JavaScript

The easiest deployment option. Copy the complete framework folder into your static resources and include the two files.

<link rel="stylesheet" href="/ui/static/ui-framework/dist/ui-framework.min.css">

<!-- Page content -->
<body class="ui-scope">
  ...
</body>

<script src="/ui/static/ui-framework/dist/ui-framework.min.js"></script>

Option 2: reusable modules

Load only the component styles and scripts needed by a page. Always load tokens and core first.

<link rel="stylesheet" href="/ui/static/ui-framework/src/css/00-tokens.css">
<link rel="stylesheet" href="/ui/static/ui-framework/src/css/01-base.css">
<link rel="stylesheet" href="/ui/static/ui-framework/src/css/05-buttons.css">
<link rel="stylesheet" href="/ui/static/ui-framework/src/css/06-forms.css">

<script src="/ui/static/ui-framework/src/js/00-core.js"></script>
<script src="/ui/static/ui-framework/src/js/05-modal.js"></script>

Server-side integration

Load the framework after your existing CSS. Wrap new content in ui-scope to apply the optional base typography safely. The paths below are plain HTML — substitute your own templating syntax (JSTL's <c:url>, Thymeleaf, PHP includes, an asset helper, etc.) to resolve them.

<link rel="stylesheet" href="/static/ui-framework/dist/ui-framework.min.css">

<main class="ui-scope">
    <!-- UI Framework components -->
</main>

<script src="/static/ui-framework/dist/ui-framework.min.js"></script>

See examples/jsp-integration.jsp in the repository for one worked example.

Theme customization

Override design tokens after the framework stylesheet. Components automatically use the new values.

<style>
:root {
  --ui-primary: #143b6b;
  --ui-primary-hover: #0d2d55;
  --ui-success: #3cb371;
  --ui-radius-3: 8px;
  --ui-font-sans: "Open Sans", Arial, sans-serif;
}
</style>

Dark theme

Set data-ui-theme="dark" on the HTML element, or use a button with data-ui-theme-toggle.
